# AtCoder Explanation (競プロ解説ノート)

AtCoderの問題解説をHTML形式でまとめているリポジトリです。
図解や数式を用いて、解法のプロセスを視覚的に分かりやすく解説することを目指しています。

## 制作体制について

本リポジトリのコンテンツは、人間とAIの共同作業によって作成されています。

* **解説構成：** Haruki07-crew
    * 問題の解法アプローチの指定、解説文の構成、図解の設計、および記述内容の監修を担当しています。
* **実装・コーディング：** AI
    * 指定されたロジックに基づいたHTML/CSSのコーディング、および解説用コードの書き出しを担当しています。
