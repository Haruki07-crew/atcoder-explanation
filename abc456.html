A問題

■ 考え方

$1$〜$6$ の目を持つサイコロを $3$ 個振ったとき、出た目の合計が $X$ になることがあるかを判定する問題です。

サイコロ $3$ 個の出た目の合計は、最小で $1+1+1 = 3$、最大で $6+6+6 = 18$ になります。さらに、$3$〜$18$ の すべての整数 がこの範囲内で実現可能なので、結局 $3 \leq X \leq 18$ なら Yes、そうでなければ No を出力すればOKです。

  • $X$ が $3$ 以上 $18$ 以下 → Yes
  • そうでない (つまり $X = 1, 2, 19, 20$) → No
  • 条件式は && (AND演算子) で 2 つの条件をつなぐ

■ コード (C++)

#include <bits/stdc++.h>
using namespace std;

int main() {
    int x;
    cin >> x;

    if (x >= 3 && x <= 18) {
        cout << "Yes" << endl;
    } else {
        cout << "No" << endl;
    }
    return 0;
}

B問題

■ 考え方

サイコロが 3 個あり、それぞれ 6 面を持っています。3 個を同時に振ったとき、出た目が 「4, 5, 6 が 1 つずつ」 になる確率を求める問題です。

確率 = (条件を満たす出方の数) ÷ (全部の出方の数) なので、次の 2 つを数えればよいです。

  • 分母: $6 \times 6 \times 6 = 216$ (どのサイコロも 6 通り)
  • 分子: 3 つのサイコロから 1 面ずつ選んだとき、その目を並べて {4, 5, 6} になる組み合わせの数

下の図のように サイコロ 1, 2, 3 から 1 面ずつ選ぶ 全部の組み合わせ (216 通り) を試して、選んだ 3 つの目をソートしたときに $(4, 5, 6)$ になっていれば「条件を満たす出方」としてカウントします。図ではサンプルとして次のサイコロを使います。

  • サイコロ1: $1, 2, 3, 4, 5, 6$
  • サイコロ2: $4, 4, 5, 5, 6, 6$
  • サイコロ3: $1, 2, 3, 4, 5, 6$
・・・ (全 216 通り試す) ・・・

これは i, j, k の 3重ループ で全部の組み合わせを試して、それぞれで 3 つの目を vector に入れて sort し、$(4, 5, 6)$ かどうかチェックすれば実装できます。

📝 ポイント: 「4, 5, 6 が 1 つずつ」というのは 順番を問わない ので、$(4,5,6)$, $(5,4,6)$, $(6,4,5)$ などすべて条件を満たします。これを毎回 6 通り場合分けで書くのは大変なので、3 つの目を ソートしてから $(4,5,6)$ と一致するかを判定 するのが楽です。

条件を満たす組み合わせの数を cnt としたら、求める確率は cnt / 216.0 です。実数で出力するので double にキャストし、fixed + setprecision で十分な桁数を出力します。

■ 使用するアルゴリズム

  • 全探索 (3重ループ) — 3 つのサイコロの面の選び方すべて (6×6×6 = 216 通り) を試して、条件を満たすものを数え上げます。順番を問わない条件なので、3 つの目をソートしてから比較するのがコツ。

■ コード (C++)

#include <bits/stdc++.h>
using namespace std;
#define all(v) v.begin(), v.end()

int main() {
    vector<vector<int>> a(3, vector<int>(6));
    for (int i = 0; i < 3; i++)
        for (int j = 0; j < 6; j++) cin >> a[i][j];

    int cnt = 0;
    // サイコロ1, 2, 3 から 1 面ずつ選ぶ全 6×6×6 = 216 通りを試す
    for (int i = 0; i < 6; i++)
        for (int j = 0; j < 6; j++)
            for (int k = 0; k < 6; k++) {
                vector<int> sai = {a[0][i], a[1][j], a[2][k]};
                sort(all(sai));                          // ソートして
                if (sai[0] == 4 && sai[1] == 5 && sai[2] == 6)
                    cnt++;                               // (4,5,6) ならカウント
            }

    double ans = (double)cnt / 216.0;
    cout << fixed << setprecision(15) << ans << endl;
}

C問題

■ 考え方

$S$ の空でない部分文字列のうち、同じ文字が隣り合わないもの の個数を $\bmod\ 998244353$ で求める問題です。

📝 キーとなる観察: 部分文字列 $S[l..r]$ が条件を満たす ⇔ $S[l]$ と $S[l+1]$、$S[l+1]$ と $S[l+2]$、…、$S[r-1]$ と $S[r]$ がすべて異なる。
つまり、条件を満たす部分文字列は 「隣り合う文字がすべて違う、限界まで長い区間」 にすっぽり収まっています。この区間を以下では 「良い区間」 と呼びます。

$S$ を「良い区間」たちに切り分けます。切れ目は $S[i] = S[i-1]$ となる位置 $i$ の直前 です (そこから新しい区間が始まる)。

例として $S = $ abcca を見てみましょう。位置 $2$ と位置 $3$ がどちらも c なので、ここで区間が切れます。

長さ $L$ の良い区間からは何個の部分文字列が取れるか?

長さ $L$ の良い区間の中の任意の連続部分は、それ自身も「同じ文字が隣り合わない」を満たしています。よって、その区間からは 始点と終点の選び方の総数、つまり

$1 + 2 + \cdots + L = L(L+1)/2$ 個

の良い部分文字列が取れます。例えば $L = 3$ の良い区間 abc なら:

  • 長さ 1: a, b, c → 3 個
  • 長さ 2: ab, bc → 2 個
  • 長さ 3: abc → 1 個
  • 合計 $3 + 2 + 1 = 6 = 3 \cdot 4 / 2$ 個

尺取り法 (two-pointer) で良い区間を切り出す

左端 l、右端 r の 2 本のポインタを使います。[l, r) が今見ている良い区間です。

  1. l = 0, r = 1 でスタート (1 文字目だけは必ず良い区間)。
  2. r < |S| かつ S[r] != S[r-1] の間、r++ で右に伸ばす。
  3. 伸ばせなくなったら [l, r) が極大な良い区間。長さは dis = r - l。答えに dis * (dis+1) / 2 を加える。
  4. 次の区間に移る: l = r, r = l + 1。
  5. l < |S| である限り 2 に戻って繰り返す。

📝 ポイント: $S[r] = S[r-1]$ になったとき、位置 $r$ は 新しい良い区間の始点 になります。1 文字を 2 つの区間で重ねて使うわけではないので、l = r と動かして OK です (区間 $[l, r)$ は半開区間で長さ $r-l$)。

$S$ の長さを $N$ とすると、r は最大でも $N$ までしか進まないので全体で $O(N)$。$N \leq 3 \times 10^5$ でも余裕で間に合います。

■ 使用するアルゴリズム

  • 尺取り法 (two-pointer) — 左端 l と右端 r を使って、$S$ を「同じ文字が隣り合わない」極大な区間に切り分け、それぞれの長さ $L$ について $L(L+1)/2$ を答えに足し込みます。

■ コード (C++)

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    string s;
    cin >> s;

    const ll MOD = 998244353;
    int n = s.size();
    int l = 0, r = 1;
    ll ans = 0;

    while (l < n) {
        // S[r] != S[r-1] の間、良い区間を右に伸ばす
        while (r < n && s[r] != s[r-1]) r++;

        // [l, r) が極大な良い区間。長さは dis
        ll dis = r - l;
        ll cnt = dis * (dis + 1) / 2 % MOD;     // L(L+1)/2 個
        ans = (ans + cnt) % MOD;

        // 次の良い区間に移る
        l = r;
        r = l + 1;
    }

    cout << ans << endl;
}

D問題

■ 考え方

C問題と問題文がよく似ていますが、こちらは 「部分文字列」ではなく「部分列」。連続でなくてもよいので、$S$ の各文字を「取る / 取らない」を選んだ $2^N$ 通りの選び方の中から「同じ文字が隣り合わない」ものを数えることになります。$N \leq 3 \times 10^5$ なので素朴な全列挙は無理。何か 賢い数え方 が必要そうです。

DPの発想に至るまで

$S$ を左から 1 文字ずつ見ていって、各位置までで作れる良い部分列の個数を更新していく、という方針を考えてみます。位置 $i$ の文字 $S[i] = g$ にやってきたとき、できることは 2 つ。

  1. この文字を 使わない → 既存の良い部分列はそのまま残る。
  2. この文字を 使う → 既存の良い部分列の末尾にこの $g$ をつなげる、または $g$ 単体で 1 文字の部分列を作る。

ここで 「つなげていいか」を判定するのに必要な情報は何か を考えると、既存の部分列の末尾の文字さえわかればよい ことに気づきます。「同じ文字が隣り合わない」という条件は、新しくつけ足す文字とその直前の文字 (= 既存部分列の末尾) だけで決まるからです。中身がどんなに長くても、間にどんな文字が入っていても関係ありません。

📝 キーとなる観察: 「これまでに作った良い部分列」は、末尾の文字でグループ分け しておけば十分。グループの中身を 1 つ 1 つ覚えておく必要はなく、個数だけ を持っておけば、新しい文字をつなげたときに何個増えるかがわかります。

$S$ に出てくる文字は a, b, c の 3 種類だけなので、グループも 3 つ。これでDPの形が見えてきました。

持つ DP の値

ある時点までの $S$ を見終わったときに、次の 3 つの値を持っておきます。

  • ba = これまで作れた良い部分列のうち、末尾が a のものの個数
  • bb = 同じく 末尾が b
  • bc = 同じく 末尾が c

合計 (答え) は ans = ba + bb + bc です。

遷移: 新しい文字 $g$ を見たとき

$S$ を左から 1 文字ずつ見ていきます。今見ている文字を $g$ としたとき、「この $g$ を新しい末尾として使う」良い部分列 がいくつ新たに作れるか考えます。

末尾を $g$ にするには、今までの良い部分列のうち 末尾が $g$ 以外 のものの後ろにこの $g$ をくっつければ OK。さらに、この $g$ 1 文字だけ でも良い部分列になります。よって新しく作れる個数は：

(末尾が $g$ 以外の個数の合計) + 1

例えば $g$ = a のときは：

  • 末尾が b の部分列に a をつけて末尾 a に → bb 通り
  • 末尾が c の部分列に a をつけて末尾 a に → bc 通り
  • この a を 1 文字だけ取る → 1 通り
  • 合計 bb + bc + 1 を ba に足す

📝 ここがポイント: 末尾が a の部分列に a をつけてはいけません (同じ文字が隣り合うので)。そのため 「自分以外」の 2 つだけ を足すのです。b, c についても同様。

例: $S = $ aba でやってみる

初期状態 ba=0, bb=0, bc=0, ans=0。これを左から処理します。

念のため列挙して確認:

  • 位置 {0}: a ✓
  • 位置 {1}: b ✓
  • 位置 {2}: a ✓
  • 位置 {0,1}: ab ✓
  • 位置 {0,2}: aa ✗ (隣り合うので不可)
  • 位置 {1,2}: ba ✓
  • 位置 {0,1,2}: aba ✓

良い部分列は 6 個。表の ans = 6 と一致しています。

計算量と mod

各文字につき定数時間で更新できるので全体 $O(N)$。値はすぐに大きくなるので、毎回の更新で $\bmod\ 998244353$ を取るのを忘れずに。

■ 使用するアルゴリズム

  • 動的計画法 (DP) — 「末尾が a / b / c の良い部分列の個数」をそれぞれ持っておき、新しい文字 $g$ を見たら $g$ 以外の 2 つの和 + 1 を $g$ の方に加算する、という遷移で全体を $O(N)$ で処理します。

■ コード (C++)

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    string s;
    cin >> s;

    const ll MOD = 998244353;
    ll ba = 0, bb = 0, bc = 0;   // 末尾が a / b / c の良い部分列の個数
    ll ans = 0;

    for (char g : s) {
        if (g == 'a') {
            ll add = (bb + bc + 1) % MOD;   // bb + bc + 1
            ba  = (ba  + add) % MOD;
            ans = (ans + add) % MOD;
        } else if (g == 'b') {
            ll add = (ba + bc + 1) % MOD;
            bb  = (bb  + add) % MOD;
            ans = (ans + add) % MOD;
        } else { // g == 'c'
            ll add = (ba + bb + 1) % MOD;
            bc  = (bc  + add) % MOD;
            ans = (ans + add) % MOD;
        }
    }

    cout << ans << endl;
}
