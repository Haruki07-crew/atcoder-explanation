A問題

■ 考え方

if 文などを使って $A \neq B$ かつ $B = C$ という条件を実装します。

条件式は &&(AND演算子) でつなぐことで、両方を同時に満たすかどうかを判定できます。

  • 「等しくない」は C++ では !=
  • 「等しい」は ==
  • 条件を満たす → Yes / 満たさない → No

■ コード (C++)

#include <bits/stdc++.h>
using namespace std;

int main() {
    int A, B, C;
    cin >> A >> B >> C;

    if (A != B && B == C) {
        cout << "Yes" << endl;
    } else {
        cout << "No" << endl;
    }
    return 0;
}

B問題

■ 考え方

イメージとして、下の図のように 見ていく長方形の範囲を全部試す。赤色で囲んだ領域が今見ている長方形の範囲です。

まずは 1行だけの長方形 を左上から順に試していきます (グリッドの座標は左上を $(0,0)$ とします)。

・・・

次に 2行以上の長方形 に切り替えて、また同じように左上から順に試していきます。

・・・

このように見ていく長方形の範囲を全部列挙して、それぞれの長方形が 点対称 に塗られているかを判定し、条件を満たすなら答えに $+1$ します。

長方形の左上の行を $h_1$、下の行を $h_2$、左の列を $w_1$、右の列を $w_2$ として、外側の 4重ループ で全ての長方形を列挙します。さらに長方形内の各マスを見るための 2重ループ を内側に入れて、合計 6重ループの構成になります。

📝 ポイント: 点対称 の判定式は、実は 問題文の中ですでに与えられている ので、自分で導出する必要はありません。問題文に書かれている式 マス $(i,j)$ とマス $(h_1+h_2-i,\; w_1+w_2-j)$ が同じ色 をそのまま条件式として書けば OK です。

  • 長方形 $(h_1, w_1)$~$(h_2, w_2)$ の中を $i, j$ で走査
  • マス $(i, j)$ と点対称の位置にあるマス $(h_1 + h_2 - i,\; w_1 + w_2 - j)$ を比較 ← 問題文の式そのまま
  • すべて同じ色なら点対称 → 答えに $+1$

■ 使用するアルゴリズム

  • 多重ループ — 長方形の枚挙に4重ループ ($h_1, h_2, w_1, w_2$)、長方形内のマスの走査に2重ループ ($i, j$) を組み合わせて、合計6重ループで実装します。

■ コード (C++)

for (int h1 = 0; h1 < h; h1++) {
    for (int h2 = h1; h2 < h; h2++) {
        for (int w1 = 0; w1 < w; w1++) {
            for (int w2 = w1; w2 < w; w2++) {
                bool flag = true;
                for (int i = h1; i <= h2; i++)
                    for (int j = w1; j <= w2; j++)
                        if (s[i][j] != s[h1 + h2 - i][w1 + w2 - j])
                            flag = false;
                if (flag) ans++;
            }
        }
    }
}

C問題

■ 考え方

「整数 $x$ を選んで、$A_i = x$ なるすべての $i$ について $A_i$ を $0$ に置き換える」という操作をちょうど $K$ 回行ったあとの総和の最小値を求める問題です。

1回の操作で総和は (その値) × (その値の出現回数) だけ減ります。つまり、配列 $A$ の総和を最初に ans として持っておき、そこから「値 × 出現回数」が大きい順に $K$ 個選んで引けばよい、という形に言い換えられます。

具体的な手順は以下の通り。

  1. 配列 a の総和を ans に入れる。
  2. 配列 a を小さい順にソートする (同じ値が連続して並ぶようにするため)。
  3. ランレングス圧縮を使って、(値, 出現回数) のペアの列 ran を作る。
  4. 新しい配列 sum を作って、各ペアについて 値 × 出現回数 の値を入れる。
  5. sum を 大きい順 にソートする。
  6. $i = 0, 1, \dots, K-1$ について ans -= sum[i] する (ただし sum.size() が $K$ 未満の場合はそこまで)。
  7. 最後に ans を出力。

■ 使用するアルゴリズム

  • ランレングス圧縮 — ソート済み配列を頭から見て、直前と同じ値ならカウントを増やし、違う値なら新しいペアを追加するだけ。今回は ran.back().first と現在の値を比較して実装しています。

■ コード (C++)

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    int n, k;
    cin >> n >> k;

    vector<ll> a(n);
    ll ans = 0;
    for (auto &g : a) cin >> g, ans += g;   // ans = 総和

    sort(a.begin(), a.end());                // 小さい順にソート

    // ランレングス圧縮: (値, 出現回数) のペア列を作る
    vector<pair<ll, ll>> ran;
    for (int i = 0; i < n; i++) {
        if (!ran.empty() && ran.back().first == a[i]) {
            ran.back().second++;
        } else {
            ran.push_back({a[i], 1});
        }
    }

    // 値 × 出現回数 を sum に入れる
    vector<ll> sum;
    for (auto &g : ran) sum.push_back(g.first * g.second);

    // 大きい順にソート
    sort(sum.rbegin(), sum.rend());

    // 上位 K 個を ans から引く
    for (int i = 0; i < min((int)sum.size(), k); i++) ans -= sum[i];

    cout << ans << endl;
}

D問題

■ 考え方

カード $C_i$ と その上に乗っているカードたち をひとかたまりにして、別の山の一番上 (カード $P_i$ の上) に移す操作を $Q$ 回行います。

素直に「毎回カードを 1 枚ずつ持ち上げて移動」してしまうと、移動するカードの枚数が多いとき (たとえば 30 万枚をまるごと運ぶような場合) に時間がかかりすぎてしまい、$Q$ 回繰り返すとどう頑張っても間に合いません。

そこで実際にカードを動かす代わりに、「それぞれのカードについて『すぐ下にあるカード』と『すぐ上にあるカード』をメモしておく」 という方法を使います。こうすると、何枚カードが乗っていようと 1 回の操作で書き換える場所はたった数か所 で済みます。

📝 使う配列

  • l[c] = カード c の すぐ下 にあるカードの番号 (下に何もなければ -1)
  • u[p] = カード p の すぐ上 にあるカードの番号 (上に何もなければ -1)

初期状態

各山にはカード 1 枚ずつ。すべての l[i], u[i] は -1。

1回の操作 $(c, p)$ でやること

  1. befo = l[c] として、c が今まで乗っていたカード を覚えておく
  2. もし befo != -1 なら、u[befo] = -1 にする
    (c が抜けたので、c が乗っていたカードの上には今、何もない)
  3. l[c] = p にする (c のすぐ下は今や p)
  4. u[p] = c にする (p のすぐ上は今や c)

📝 ここがポイント: c の上に乗っているカードたち のメモ (u[c], u[u[c]] ...) は 1 つも触る必要がありません。それらの「すぐ上」「すぐ下」の関係は変わっていないからです。c が p の上に移動するだけで、c の上の塊は 自動的にいっしょに運ばれている ように扱えます。

例: $N = 4$ で 2 回操作してみる

操作1: $(c, p) = (1, 2)$ — カード 1 をカード 2 の上に移動

操作2: $(c, p) = (2, 3)$ — カード 2 (とその上のカード 1) をカード 3 の上に移動

各山の枚数の数え方

すべての操作を終えたあと、山 $i$ の枚数を次のように求めます。

  • カード $i$ が他のカードの上に乗っている (l[i] != -1) なら、山 $i$ にはもう何もない → 0 を出力
  • そうでなければ、カード $i$ が山 $i$ の一番下にいるということ。$i$ から 「すぐ上のカード」をたどっていって (cur = u[cur])、-1 になるまでカウントすればその山の枚数になる

各カードはちょうど 1 つの山にしかいないので、たどっていく合計の手間は全部合わせてもカードの枚数 $N$ 程度。全体としてかなり高速に動きます。

■ 使用するアルゴリズム

  • 「すぐ上」「すぐ下」のメモを持つ方法 — それぞれのカードに「自分のすぐ下のカード番号」と「自分のすぐ上のカード番号」を覚えておくことで、何枚カードが乗っていてもひとかたまりの移動を 数か所のメモを書き換えるだけ で済ませる方法です。

■ コード (C++)

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    int n, q;
    cin >> n >> q;

    // l[c] = c の直下のカード, u[p] = p の直上のカード
    vector<int> l(n, -1), u(n, -1);

    while (q--) {
        int c, p;
        cin >> c >> p;
        c--; p--;                       // 0-indexed に直す

        int befo = l[c];                // c が今乗っているカード
        if (befo != -1) u[befo] = -1;   // c が抜けた山の頂上をクリア
        l[c] = p;                       // c は p の上に来た
        u[p] = c;                       // p の上は c
    }

    // 各山 i の枚数を求める
    for (int i = 0; i < n; i++) {
        if (l[i] != -1) {
            // i が他のカードの上に乗っている → 山 i は空
            cout << 0;
        } else {
            // i から u[] を辿ってカウント
            ll cnt = 0, cur = i;
            while (cur != -1) {
                cnt++;
                cur = u[cur];
            }
            cout << cnt;
        }
        cout << " ";
    }
    cout << endl;
}
